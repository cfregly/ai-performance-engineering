## Maintenance guidance

- Keep CPU, GPU, sanitizer, profiler, NVSHMEM, and optional-dependency CI lanes separate, with skipped tests visible and explained.
- Require structured argument vectors at every execution boundary and apply shared response redaction at every external output boundary.
- Retain strict malformed-output and precision-oracle negative controls; they caught false passes that ordinary happy-path tests missed.
- Bind GPU and profiler evidence to a source manifest and record the actual captured kernel identity, not only the profiler exit code.
- Treat prior performance tables as historical after precision or workload changes. Regenerate them only from qualified, manifest-matched runs.
- Run concurrent benchmark suites in separate processes. Device visibility is restored for sequential reusable calls, but process-wide environment mutation is not thread-safe.
- Keep timing units explicit: PyTorch Timer reports observed block means, while CUDA event mode reports measured iterations. Never manufacture a requested sample count from a single aggregate.

No full 486-benchmark sweep or multi-node qualification was completed, and no performance improvement is claimed.
