# Reader-facing checks

Start with a concrete example, explain the mechanism, then show the supported
comparison and its scope. Keep units, assumptions, material tradeoffs and limits
visible. A chart must help the reader make the stated decision.

A measured comparison needs retained measured evidence for its declared stage
and conditions. A source-reported comparison needs named primary-source
attribution and its own retained review. Neither state can be created by a
caption, a file hash or a favorable illustrative number.

The separate [analytical contract](ANALYTICAL_PACKAGE.md) supports one named
package only after an explicit human instruction. It uses synthetic arithmetic,
not measured performance. It requires retained derivation code and results,
independent recalculation, explicit assumptions and limitations, and no implied
measured runtime or speedup. Authorization for one package does not authorize
another package or publication.

When reader visuals are required, the current article and saved X/LinkedIn copy
must follow the declared sequence. Attach the actual scientific comparison on
both platforms and inspect the real phone preview after upload. A decorative
cover or a chart URL does not replace that visible comparison.

Keep image sources, saved attachment identities, screenshots and review findings
bound to their current bytes. Detailed scientific previews use one image per
post or a document page. Inspect every attached document page for crop, overlays
and readable key labels. A local rendering alone does not establish the actual
platform appearance.

A review receipt records an actual review. Hashes identify its inputs but cannot
prove reviewer independence, arithmetic correctness, comprehension or readable
pixels. Changed inputs need current bindings and review of the change. Keep
coordination and reviewer bookkeeping outside reader copy.

These checks do not execute a GPU workload, qualify a benchmark, schedule a
post or publish content. The complete package check and the user's separate
publication authorization still apply.
