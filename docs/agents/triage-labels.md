# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Evaluation is waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | The issue requires human judgment or access to implement. |
| `wontfix` | `wontfix` | The maintainer has decided to close the issue without implementing a change. |

Use the GitHub label in the middle column when a skill refers to a triage role.
