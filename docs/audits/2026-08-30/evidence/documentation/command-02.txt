                                                                                
 Usage: python -m cli.aisp bench verify [OPTIONS]                               
                                                                                
 Verify benchmark pairs for correctness without measuring performance.          
                                                                                
 Runs verification checks on baseline/optimized benchmark pairs: - Input        
 signature matching (same batch size, dtypes, shapes) - Output correctness      
 (optimized produces same outputs as baseline) - Jitter check (outputs change   
 when inputs are perturbed) - Fresh-input check (different seeds produce        
 different outputs) - Workload invariant check (same bytes/tokens/ops per       
 iteration)                                                                     
 Examples:     aisp bench verify                     # Verify all chapters      
 aisp bench verify -t ch11            # Verify chapter 11     aisp bench verify 
 -t ch11:streams    # Verify specific example     aisp bench verify --json      
 # JSON output for CI
