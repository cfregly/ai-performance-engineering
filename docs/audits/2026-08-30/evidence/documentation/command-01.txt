                                                                                
 Usage: python -m cli.aisp bench run [OPTIONS]                                  
                                                                                
 Run benchmarks - discover, run, and summarize results.                         
                                                                                
 CUDA binaries execute only via Python wrappers (CudaBinaryBenchmark).
